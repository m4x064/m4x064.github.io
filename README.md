# Math Fit | UFOゆーりの数式ステーション

HTML/CSS/JavaScriptだけで動く、UFOゆーり世界観つきの簡易適応型数学診断ゲームです。

## 遊び方

`index.html` をブラウザで開き、好きなミッションを選んでください。

10問の計算問題に答えると、正答率、到達レベル、平均解答時間、分野別の結果が表示されます。

入力方法は端末に合わせて切り替わります。

- パソコン: キーボードで入力してEnterで回答します。
- スマホ: 画面内の数字パッドで入力します。
- 回答後は、もう一度Enterを押すとすぐ次の問題に進みます。
- 途中のミッションはブラウザに保存され、タイトルの `つづきから` で再開できます。
- 累計正解数に応じて、ゆーりLvとごほうびアイテムが増えます。

PowerShellでローカルサーバーを使う場合は、このフォルダーで起動します。

```powershell
cd github-pages
python -m http.server 5173
```

その後、`http://localhost:5173/` を開いてください。

## ミッション

- `10問診断ミッション`: 分数・割合・文字式の入口までを短く診断します。
- `一桁スター航路`: 0を含む一桁どうしの基礎問題をランダムに練習します。
- `繰り上がりジャンプ航路`: 繰り上がり足し算と二桁になる掛け算を練習します。
- `二桁スリム航路`: 二桁と一桁のひき算・わり算で、答えが一桁になる全通りを練習します。
- `二桁ペア航路`: 二桁どうしのひき算・わり算で、答えが一桁になる全通りを練習します。
- `四則演算ナビ`: たし算・ひき算・かけ算・わり算の基本を確認します。

## 適応ルール

- 初期レベルは1です。
- 正解かつ速い回答、または連続正解でレベルが上がります。
- 不正解の場合はレベルが下がります。
- レベルが上がると数値範囲が広がり、かけ算・わり算も出題されます。
